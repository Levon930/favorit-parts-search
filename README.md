# favorit-parts-search

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
cp .env.example .env
npm run dev
```

Приложение откроется на http://localhost:5173.

## Переменные окружения

| Переменная        | Что это                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| `FAVORIT_KEY`     | ключ покупателя Favorit Parts. В `.env.example` демо-ключ из документации API, с ним API отвечает |
| `FAVORIT_API_URL` | адрес сервиса «Проценка». По умолчанию `http://api.favorit-parts.ru`                              |

Переменные читает только dev-сервер Vite: он проксирует запросы `/api` на `FAVORIT_API_URL` и сам добавляет `key`. В браузер и в бандл ключ не попадает.
